В рамках лабораторной работы я изучаю основы работы с системой контроля версий Git.
Git — это распределённая VCS, которая позволяет отслеживать изменения в файлах проекта и координировать работу команды разработчиков.
Я научился клонировать репозиторий с GitHub на локальную машину и выполнять базовые команды: git add, git commit и git push.
Также я освоил работу с ветками (branching), что позволяет изолировать разработку новых функций от стабильной версии проекта.
Кроме того, я разобрался с механизмом Pull Request, который используется для ревью кода и безопасного слияния изменений в основную ветку main.
GitHub предоставляет удобную веб-платформу для хостинга проектов, управления задачами через Issues и совместной работы над кодом.
